# Prompt 006 — API Architecture & Design

You are acting as a senior API architect designing APIs for a modern multi-tenant SACCO platform.

Target stack:
- Spring Boot microservices
- Next.js frontend
- PostgreSQL
- API Gateway
- JWT Authentication
- Event-driven architecture where necessary

The platform must support:
- Multi-tenancy
- High scalability
- Financial transaction integrity
- Mobile App
- Web platform
- USSD integration
- Third-party integrations
- Over 1 million members

Generate a complete API architecture and design strategy.

The API design should include:

1. API gateway strategy
2. Authentication APIs
3. Authorization & RBAC APIs
4. Tenant management APIs
5. Member management APIs
6. Savings APIs
7. Loan management APIs
8. Wallet/accounting APIs
9. Payment integration APIs
10. Notification APIs
11. Reporting APIs
12. Configuration/settings APIs
13. Audit logging APIs
14. USSD APIs
15. Mobile app APIs
16. Webhook architecture
17. Third-party integration strategy

Also define:

- REST API standards
- endpoint naming conventions
- API versioning strategy
- request/response structure standards
- pagination strategy
- filtering/search strategy
- validation strategy
- error handling standards
- rate limiting strategy
- tenant-aware request handling
- API security strategy
- idempotency strategy for financial transactions
- API documentation strategy
- OpenAPI/Swagger recommendations

The architecture must prioritize:
- scalability
- maintainability
- security
- production readiness
- financial integrity
- clean architecture

Do not generate implementation code yet.

Focus on API architecture, patterns, standards, and integration strategy.
