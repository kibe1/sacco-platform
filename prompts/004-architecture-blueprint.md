# Prompt 004 — Architecture Blueprint Generation

You are acting as a principal enterprise architect designing a next-generation SACCO platform.

The platform is a multi-tenant financial ecosystem built for scalability, configurability, and high availability.

Target stack:
- Next.js frontend
- Spring Boot microservices
- PostgreSQL
- Docker/Kubernetes
- Kafka/Event-driven communication
- API Gateway
- Redis caching
- JWT authentication

Generate a complete architecture blueprint for the platform.

The blueprint should include:

1. High-level system architecture
2. Frontend architecture
3. Backend microservice boundaries
4. API gateway flow
5. Authentication and authorization flow
6. Multi-tenant isolation model
7. Database architecture
8. Event-driven communication flow
9. Payment processing flow
10. Loan processing flow
11. Savings transaction flow
12. Notification flow
13. USSD integration flow
14. Mobile app integration flow
15. Reporting architecture
16. Audit and logging flow
17. Deployment topology
18. Container orchestration strategy
19. Caching strategy
20. Monitoring and observability architecture

Also generate:
- recommended service interaction patterns
- request lifecycle flows
- synchronous vs asynchronous communication strategy
- tenant-aware architecture recommendations
- scalability recommendations
- failover and resiliency considerations

Do not generate implementation code yet.

Focus on:
- clean architecture
- enterprise financial system standards
- production readiness
- maintainability
- scalability
- configurability
- security
- multi-tenancy
