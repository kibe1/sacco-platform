# Prompt 002 — Frontend UI Research

You are helping design the frontend architecture for a modern SACCO platform.

Target stack:
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- Zustand
- React Hook Form
- Zod
- PWA support

Research and propose the best frontend structure for an enterprise SACCO admin portal.

The portal must support:
- multi-tenancy
- tenant branding
- responsive dashboard
- role-based navigation
- member management
- savings management
- loan management
- wallet management
- accounting
- reports
- settings
- USSD/mobile configuration

Do not write production code yet.

Produce:
1. recommended folder structure
2. layout strategy
3. reusable component strategy
4. dashboard structure
5. form strategy
6. table/data-grid strategy
7. state management strategy
8. API integration strategy
9. tenant branding strategy
10. accessibility and mobile responsiveness notes
