# Prompt 003 — Technical Specification Generation

You are acting as a senior enterprise solution architect designing a modern SACCO platform.

The system is being rebuilt from a legacy tightly coupled system into a modern API-first microservice architecture.

Target stack:
- Next.js
- Spring Boot
- PostgreSQL
- Docker
- Kafka (where necessary)

The system must support:
- Multi-tenancy
- Over 1 million members
- PWA support
- Mobile App
- USSD integration
- Web platform
- Containerized deployment
- High scalability
- Configurable business rules
- Tenant branding

Generate a comprehensive technical specification document.

The specification should include:

1. System overview
2. Architecture overview
3. Frontend architecture
4. Backend microservices architecture
5. API gateway strategy
6. Authentication & authorization strategy
7. Multi-tenancy architecture
8. Database architecture
9. Messaging/event-driven architecture
10. File storage strategy
11. Reporting architecture
12. Audit & logging architecture
13. Notification architecture
14. Payment integration architecture
15. Deployment architecture
16. DevOps & CI/CD considerations
17. Security considerations
18. Scalability strategy
19. Disaster recovery considerations
20. Monitoring & observability strategy

Do not generate implementation code yet.

Focus on:
- scalability
- maintainability
- configurability
- clean architecture
- financial system security
- production readiness
